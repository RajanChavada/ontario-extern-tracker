## What is a talent pool posting?

A talent pool (some hospitals say "candidate pool") is a posting a hospital uses to collect applications before specific jobs open. When a unit needs an extern, the hospital can hire from the pool. Applying doesn't mean a job is waiting for you.

## What is a real vacancy?

A vacancy posting is for a position that exists now. Some postings state how many positions they're filling. Others say they're posted for an existing vacancy without giving a number.

## How to tell which one you're looking at

- **Read the title.** "Talent Pool" in the title, as on SHN's posting, is the clearest sign.
- **Look for the wording.** "Not for an existing vacancy", "candidate pool" and "future opportunities" mean a pool. "Existing vacancy" or a number of positions means a vacancy.
- **If it says neither,** the posting doesn't tell you. The tracker labels those "posting live".

## Should you apply to a talent pool?

If you meet the listed criteria, it's the same application as for a vacancy, and the pool is how the hospital says it fills upcoming openings. Just don't make it your only application: a pool has no set number of jobs behind it. Apply to the vacancies you qualify for too.

## How the tracker labels them

Every open listing on [ontarioexterns.ca](/) is marked "Open · talent pool", "Open · positions listed" or "Open · posting live", so you can tell them apart before you click. Talent pools are never counted as vacancies.

## FAQ

**Is a talent pool a real job posting?** It's a real posting on the hospital's own job site, but it isn't for one specific open job. It collects candidates for upcoming openings.

**Does a talent pool have a closing date?** Some do. Scarborough Health Network's closes {{shn.deadline|date}}. Mackenzie Health's shows no closing date.

**Is a talent pool the same as a waitlist?** Not exactly. A pool collects applications for openings that haven't been posted yet; each hospital decides how and when it hires from it. Check the posting's own wording.
